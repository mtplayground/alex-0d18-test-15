# Product Contract

## What This Project Is

A static, browser-only plain-text todo editor. Users manage todos in a full-screen textarea where each non-empty line is one todo item.

## Current Capabilities

- Full-screen controlled text editor.
- One todo per non-empty line.
- Live bottom status bar showing the current non-empty todo count.
- Debounced autosave to browser `localStorage`.
- Refresh persistence: saved text is restored on page load.
- Clear button with native confirmation before deleting all text.
- Clear action resets the editor and synchronizes storage.

## Architecture

- Vite + React + TypeScript single-page app.
- Tailwind CSS via `@tailwindcss/vite`.
- App state is held in React and persisted through `useLocalStorage`.
- Todo counting is centralized in `src/lib/countTodos.ts`.
- UI is split into `PlainTextEditor` and `StatusBar` components.
- No backend, database, authentication, or server runtime.

## Data And Persistence

- The todo text is stored as one string in browser `localStorage`.
- Current storage key: `todos:text`.
- The persistence hook tolerates plain strings and JSON values, catches storage errors, and supports debounced writes.
- User data stays in the browser; static hosting infrastructure does not receive todo content.

## Conventions

- Development and preview servers listen on `0.0.0.0:8080`.
- Browser-exposed environment variables must use the `VITE_` prefix.
- Static production output is generated by `npm run build` into `dist/`.
- Self-hosted deployments should serve `dist/` and fall back unknown routes to `index.html`.

## Validation

- Formatting: `npm run format:check`
- Lint: `npm run lint`
- Unit tests: `npm run test`
- End-to-end test: `npm run test:e2e`
- Production build: `npm run build`
